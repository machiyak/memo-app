# Flask Memo App

## 概要

FlaskとSQLiteを用いて作成した簡易メモアプリです。
Webアプリケーションの基本的な構造を理解するために実装しました。

## 注意

`app_vulnerable.py` はWebセキュリティ学習用に意図的に脆弱な実装を含んでいます。
ローカル環境での検証のみを目的としており、公開サーバー上では実行しないでください。

## 現在の機能

- メモの投稿
- SQLiteへの保存
- 保存済みメモの一覧表示
- ユーザー登録機能（メモは全体で共有）

## 学んだこと

- Flaskのルーティング
- HTMLフォームからPOSTされた値の取得
- SQLiteの操作
- SQL Injectionを避けるためのプレースホルダの使い方
- セッション管理
- パスワードのハッシュ化
- ログイン中ユーザーごとのメモ分離
- 所有者チェック付きのメモ削除制御
